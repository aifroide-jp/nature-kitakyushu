夏休み自然体験キャンプ ― 2泊3日で学ぶ北九州の自然

2026年7月26日(土)〜28日(月)  2泊3日（26日 9:00集合 / 28日 15:00解散）

イベント内容

2泊3日の本格的な自然体験キャンプ。北九州市内の豊かな自然の中で、野外炊事・昆虫観察・星空観察・川遊びなど、教室では体験できないリアルな自然体験をたっぷりと楽しみます。

「生き物が好き」「自然の中で思いきり遊びたい」という子どもたちのために設計された3日間です。専門スタッフが24時間サポートしますので、はじめてのキャンプ参加でも安心です。持ち物リストは申込完了後にメールで送付します。

タイムスケジュール

【1日目】7/26 9:00 集合・テント設営 / 12:00 野外炊事・昼食 / 14:00 川遊び・生き物調査 / 19:00 焚き火・星空観察
【2日目】7/27 6:30 朝の鳥観察 / 9:00 昆虫・植物フィールドワーク / 13:00 自然素材工作 / 18:00 環境クイズ大会 / 20:00 ナイトウォーク
【3日目】7/28 7:00 朝食・清掃・撤収 / 10:00 まとめ発表会 / 12:00 昼食 / 15:00 解散

注意事項

⚠ 雨天・悪天候について

雨天時は一部プログラムを変更して実施します。荒天（雷・強風）の場合は安全を最優先とし、プログラムを変更または一部中止します。大型台風等の場合は前日までにご連絡します。

📋 対象・お申し込みについて

・対象：小学3〜6年生（単独参加可）
・保護者の同意書が必要です（申込後に送付）
・持ち物リストは申込完了後にメールで送付します
・食物アレルギーのある方は申込時にご記入ください
